# Avondale Events Website

A static front-end website for the Avondale event list, built with [Astro](https://astro.build/) and React. The site loads its event data from `public/events.json` in the browser.

Run `npm run dev` for local development. Run `npm run check` to check the project and `npm run build` to generate the static site in `dist/`. Use `npm run preview` to preview the generated site locally.

See also [Avondale Event Indexer](https://github.com/smacmullan/avondale-event-indexer).
